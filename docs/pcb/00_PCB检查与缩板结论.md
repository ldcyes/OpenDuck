# PCB 绘制复核与缩板评估

2026-09-13；基于当前 R20 装配和 R13 原生电气源。已完成12种自制板、13块用板的复核。**可以继续做紧凑布局，但目前没有经过重排与复验的新板尺寸，不能把现有 PCB 等比例缩小。** 本轮评估没有改变减摆仿真所用的板形、质量和安装接口。

全部板的功能、主要芯片、连接器、尺寸、固定孔和原生原理图/PCB/BOM入口见同包《全部PCB功能与主要器件》。外购 RK3576 核心板、U2D2、BMS、TDK功率模块和相机单列；不冒充自制板，也不杜撰未公开的内部IC料号。

## 本次实际运行的检查

使用 KiCad 10.0.6，在已核字节一致的独立工程副本上运行 ERC、重新铺铜后的 DRC、全部走线错误、原理图与PCB对应检查及全部严重级别报告。原生 PCB、原理图、本地库、规则和其余公开文件共810项来源哈希在结束后再次一致。

**按现有工程声明的规则：12种板全部 ERC 0、DRC 0、未连线 0、板图不一致 0。** 没有启用保存板文件，原板字节未变。这说明当前连接和已声明几何规则通过，不能据此确认温升、载流能力、USB信号完整性或整机装配合格。

进一步在另一组副本中，把项目原来标为“忽略”的规则类别改为“警告”，其余间隙、线宽、网络类、定制规则和全部铜几何保持原值，得到以下额外结果。`--severity-all` 本身不会把“忽略”类别重新启用，所以必须区分两轮结果。

逐对象复核进一步确认：38项为29处焊线端和9处测试点，没有缺失芯片或插接器本体的庭院。按唯一板型计，10个焊线端已有局部成形/焊锡包络、17个只有背侧短尾、载板2个输入焊线端尚无局部包络；测试点需定义探针空间。5项走线警告均已用实际线宽、过孔外径和钻孔证明存在正面积名义铜接触，其中3条细短线被同网宽线包含。因此需整理走线和补装配定义，不能把这些警告直接称为断路，也不能因此认定工艺与载流合格。详见《43项警告逐对象复核》。

## 面积与压缩空间

按真实 Edge.Cuts 板框计算，13块总面积为 **16681 mm²，即166.81 cm²**。不含外购核心板、BMS和模块内部PCB；两块LEG5分别计面积。这个数字不是整机外壳占地，也不是可削减面积。

|---|---|---|
| 优先评估重排 | Entry_5V：65×45mm，2925mm²，占总面积17.53% | 重新排列8组控制/温度/握手连接器、采样与5V电源功能区，评估四层布线是否能减少绕线和占地。现有四孔中心框59×39mm，若孔位和板边安装座均不变，无法明显缩小；需同步修安装座与插拔通道。电源热铜和Kelvin采样路径仍需保留。 |

以上为依据原生布局、面积份额和已知机械接口作出的工程评估，**未给未经验证的“缩小后可制造尺寸”或节省百分比承诺**。若孔位、插头位置和线束出口必须完全不动，显著缩板空间会进一步收窄。

外购部件也给出了明确尺寸边界：Radxa CM4官方外形为55×40mm；TDK所选i7C模块本体标称34×36.8mm。它们不能随载板缩放，模块本体面积也不等于载板所需总面积。[Radxa官方产品页](https://radxa.com/products/cm/cm4/)、[TDK所选模块官方参数](https://product.tdk.com/en/search/power/switching-power/dc-dc-converter/info?part_no=I7C2W020A120V-P03-R)。

同尺度布局图只画原生封装包围框、焊盘和非金属化孔；未画铜区、配对插头、线束及散热包络。自动提取的铜/焊盘外缘空白也只用于找候选，不能把铜区、固定边和部件包络当成可随意移除的材料。

## 与当前整机和运动设计的关系

当前557件模型中只定位了7块自制板；Regen、两温保、IMU、AMP和MIC共6块尚待详细安装，U2D2和相机也没有对应完整安装实体。它们并非从重量中完全漏掉：最终运动模型已有6板及两外购模块的8组集中质量，共约63.856g（AMP项包含扬声器），但使用了继承预算/目录质量和预留重心位置，并非实测与安装完成。

因此，下一次紧凑布局应把“缩板、安装空间与真实重心”一起闭合。新增准确CAD与实物质量时，要替换已有预留质量并处理共享固定/线束预算，不能再次把整块板重量加一遍。本轮PCB复核与减摆对比保持同一质量基线；当前摆幅改善也不能替代这些尚未完成的安装验证。

建议先补全本次43项警告的对象定义，再对Entry_5V做一个保持功能和元件规格的紧凑布局候选；同时以TDK/回生为第二候选评估合并。候选必须交付实际KiCad文件、重铺铜后的两轮DRC、具体新尺寸、3D插拔/工具通道与电流热核算，之后才能改入当前整机。
