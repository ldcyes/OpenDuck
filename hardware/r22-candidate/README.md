## 电气检查与计算的含义

根任务对冻结副本重新执行ERC、铺铜DRC、未连接检查、原理图/PCB一致性检查，并开启原来被忽略的DRC类别，两板结果均为0。独立复核另在副本开启四类默认忽略ERC检查，结果同样为0，见`final_review/supplemental_erc/`。这不等于实机电源合格。证据在 `final_verification/freeze_v1/entry/` 与 `final_verification/freeze_v2/power_regen/`；其他板仍沿用原R13审查结果。

两板均为1.60 mm、70/35/35/70 µm铜的四层结构。线宽≥0.20 mm，铺铜间距≥0.20 mm；入口板4对、合板15对局部逃线间距为0.175 mm，逐项记录。不能把“DRC为0”改写成全板任何间距均≥0.20 mm。孔铜厚度、塞孔填孔/盖铜、叠层与细间距均须由加工厂确认，见两板制造报告。

入口板用实际保存的铜区、走线、焊盘和贯穿孔建立直流电阻网格；含地回流的MOBILE与BENCH路径估计分别较原板降低50.67%与47.01%。这是数值铜路估算，源端/负载端焊点、线束、接头和动态纹波另计。保守设计预算下2.7 A板端约4.835 V仍未扣纹波与外部线损，不是整机满载验收值。

合板所选回生板内铜回路约4.866 mΩ@20°C；条件12.121 A时约59 mV、0.715 W。原两板纯板内铜约3.043 mΩ但不含删除的板间正负线对与接点，不能单凭合板宣称总回路降阻。12个换层孔的最大估计分流约9.9%，孔铜25 µm仍是假定。实际钳位上界、MOS开关损耗、回生脉冲和散热必须测试；RH050标称50 W不能直接当作机器人内可连续耗散50 W。

## 结构、模型与质量

Blender含三个场景：完整装配、入口板安装细节、合板/卧装电容/托架细节。733项表示468项原R20保留几何加265项新装态几何/包络，不是733个采购或制造件；另有9项拔插服务包络。各物体可以单独选取、隐藏，并查看原文件及所属关节。短线束预算不代表整机完整布线，保守器件包络不用于按体积计算器件重量。

入口板保留原底脚位置，改四孔框架与5 mm PEEK隔柱；背面元件2.7 mm高，对框架有名义2.3 mm余隙。四个M2工具通道用1.5 mm内六角L形扳手的Ø2×30 mm工作段核验。电容托架使用原H1/H2、不增加PCB孔，正X泄压端开放。套管上端已从z8.1改至7.9 mm；[精确STEP子集及间隙证据](mechanics/insulation_v2/subset_proof.json)确认两处原参考模型微交叠消除，套管到弯脚工程包络的最小名义距离约0.025 mm。这处很小的名义间隙仍需实物成形/绝缘验收。

安装、静态接触及按R21原轨迹关节范围的几何增量证据见 `mechanics/motion_delta/` 的最终报告。该检查可评价新几何在既定关节范围内的分离，不产生新的动力学仿真或质量/重心结论。

[有限质量与重心审查](integration/mass_review/质量与重心影响_有限范围审查.md)显示：增加内层铜后，五块新旧裸板材模型的铜名义增加约2.741 g；裸材减少约0.937 g，加本次附件毛差后名义约+0.04 g，误差足以改变符号。器件、焊料、换插头及完整线束未称量，不能给出精确新整机质量或COM，也不能继承R21动态平衡、扭矩或行走放行。

## 仍需闭合的实际工程项目

1. 合板到机身的主支架、完整电阻/电源线束、热连接与装入顺序。电容托架只固定电容到PCB，不能视为完成PCB到机身的主支承。
2. 加工厂叠层、孔铜、填孔盖铜、局部细间距及装配工艺；卧装电容成形和绝缘、绑带拉脱与热蠕变、M2叠层拧紧试样。
3. 5V全负载/低输入/纹波/切换、电源温升、回生瞬态与功率电阻温度；最终质量替换后重新核对重心和运动，再进行实体受载与行走验收。

本次不改变RK3576软件接口、保护阈值或历史训练权重。来源与分别适用的许可沿用[仓库NOTICE](https://github.com/ldcyes/OpenDuck/blob/main/NOTICE.md)；历史原生设计和交付包未覆盖。
