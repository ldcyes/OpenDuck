# R22 Power + Regen 实际合板验证记录

2026-09-14，KiCad 10.0.6。结论为可编辑设计完成、规则与电气对应验证通过；无样机。当前记录不授予连续电流、回生脉冲、整机低电量、制造良率或运动认证。

## 结构与源等价

原板面积 3900 + 960 = 4860 mm²。合板为 `(0,-10),(28,-10),(28,-15),(50,-15),(50,0),(65,0),(65,60),(0,60)` 阶梯轮廓，面积 4510 mm²，减少 7.20%；65×75 mm 仅为外包矩形，不冒充实面积。保留原 65×60 投影、TDK i7C2W020A120V-P03-R 全尺寸模块和四个 Ø2.2 mm 安装孔 (3,3)、(62,3)、(3,57)、(62,57)。原位向下 65×70 扩展方案因真实负载架/五金冲突被放弃。

84 个元件、292 个实际焊盘实例逐项对值、MPN、编号和网络。删去 Regen W1/W2 板间重复 SERVO_BUS/GND 端接和其四个独立板安装孔；原理图仅去掉重复 GND 电源旗。所有映射见 `merge_mapping.json`。回生编号 +100、独立网 `RG_` 前缀，仅 SERVO_BUS/GND 共享。检查的 110 个源文件 SHA 无变化。源清单仅指现行 `work/r13-electronics/inherited/TDK_Power_R8/` 和 `Regen_R8/`，不是旧生成器。

主板 U3/U4、回生 U105 的 MSOP 焊盘改为 TI DGS0010A 官方 1.45×0.30 mm land，0.5 mm pitch，器件、引脚中心和本体不缩放。依据 [INA226 官方图](https://www.ti.com/lit/ds/symlink/ina226.pdf) DGS0010A 4221984/A，PDF 第39页。C101 换卧装引脚封装但不换料。J1 唯一 MPN 替换：原 SM08B-SRSS-TB(LF)(SN) 侧插通道穿既有 SP3/SP4 导线，实际 BM08B-SRSS-TB(LF)(SN) 顶插在相同 (60,20)/90° 位置通过 HOME 实形筛查；八针网络、配壳和端子不变。[JST SH 官方图](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf) 配对高 6.3 mm，工程预留6.5 mm；保守外包框不等于精确塑料实体。

## 布线与制造

实际四层板，3486 段线、185 个贯通孔；最细线 0.20 mm，零段低于0.20 mm。新信号默认路由避让目标0.205 mm；保留全部电源大电流通道并加宽回生路径；`Main_Copper_Preservation.json` 独立核对源 BAT_SW/REG_RAW/MID_DRAIN/PRE_SHUNT/SERVO_BUS 所有≥0.65 mm主干的原中心线和至少原线宽。全部大电流主干走外层。

实际原生叠层总厚1.600 mm：阻焊0.010 / F.Cu0.070 / prepreg0.185 / In1.Cu0.035 / core1.000 / In2.Cu0.035 / prepreg0.185 / B.Cu0.070 / 阻焊0.010 mm。FR4、ENIG；这是工程名义堆叠，制造商须接受外层成品铜最小70 µm、孔壁最小25 µm及总厚公差，不能以“2 oz”推断孔壁厚度。

最终自定义规则明确：全局铜间距最低0.16 mm、所有线宽最低0.20 mm、所有 Zone 参与的间距最低0.20 mm。专门的 Zone 规则避免 KiCad 全局自定义规则覆盖局部铺铜属性的问题。由 kicad-cli 重新铺铜并保存后复验。另作全局0.20 mm严格副本诊断：仅15对局部信号焊盘/逃线/过孔组合为0.175 mm，全部有实际坐标和 UUID，见 `Fabrication_Local_Clearances.json`；涉及 Zone 的不足0.20 mm为0对。这些属于明确的0.16 mm最低制造规则内几何，不是忽略条目或放宽失败规则。

0.2 mm成品孔/0.45 mm焊盘、源热孔和 C10.2 新接地孔有焊盘内过孔，要求 IPC-4761 Type VII 填孔盖铜和平整化，不能按敞孔工艺默认焊接。12个主电流换层孔：x=30.8/31.6/32.4/33.2、y=7.2/8/8.8 mm，成品孔0.3 mm/铜盘0.6 mm，明确25 µm最小孔铜。焊盘和实际内外层铜均存在；没有删地铜换取通过。6个 AWG16 端接保持6 mm铜盘/2.4 mm孔；5个 AWG28 pigtail保持1 mm盘/0.5 mm孔。增加真实焊接占用庭院，信号线还须按接口的独立线束包络固定。

## 电容、插头与热源安装

C101 原件 Panasonic EEUFR1C222，2200 µF/16 V；非25 V。本体名义 D12.5×20 mm，设计上限 D13×22 mm，卧装本体 x=6..28、y中心−3.5、z中心9.1 mm，正面最高z15.6 mm（PCB正面z1.6，元件高14 mm），本体离板1 mm。依据 [Panasonic FR 系列](https://industrial.panasonic.com/cdbs/www-data/pdf/RDF0000/ABA0000C1259.pdf)。正/负成型脚焊孔分别 (1.8,−6)/(1.8,−1)。封口外至少2 mm直脚、弯曲半径至少1 mm，夹具支撑封口；独立绝缘托架承担机械载荷，不能靠两根脚悬臂承重。+X泄压端必须通畅。其上限包络至 RS101 封装包络约1.125 mm、庭院约0.600 mm，夹持/装配偏差及引脚成型需样件和工艺接受。根任务负责与板架相连的独立 PEEK 夹持件，不另加板孔。

RS101 (33,−3.5)、Q101 (43,−3.5)、W103/104 (32,−11.5)/(44,−11.5)。RH 两根 AWG16 先沿+Z直出10 mm；J1顶插直出+Z5 mm、拔插8 mm，然后弯曲R5朝+X。P101..105 先+Z6 mm、再R5朝−Y。所有背部THT引脚/锡脚上限z−1.1 mm，需剪脚实测。母板变换必须使用 R11 选定接口，旧R8世界矩阵不沿用。

外置 RH0501R000FE02 保持实际外置发热源，回生热传感不搬到控制板冒充电阻温度。源65°C电阻、75°C TDK保护边界保持。模块 Tc 点实际高度必须样测，不能用模块最高壳高代替触点。

## 承流、压降和热边界

`Current_Thermal_Screen.json` 由冻结路径几何建立条件计算。W3至W103正向主干约84.606 mm：大部分5 mm、W4邻近14 mm段3.4 mm，外层铜70 µm。20°C纯铜工程电阻约4.492 mΩ；75°C线性温度系数下5.463 mΩ。相对于3 mm初版的6.905 mΩ减少约35%。以上未计端接接触、焊盤电流展开、外线、地回流、MOS和分流器，也未把铜区并联收益当成保证。

仅在母线≤12 V且外阻≥0.99 Ω的前提下，I≤12.121 A；这不证明模拟钳位已保证12 V。此条件下正向主干约54.45 mV、0.660 W@20°C/0.803 W@75°C。12个换层孔按25 µm最小孔壁、均流计算合计截面≥0.2827 mm²、20°C约14.3 mW；孔壁和均流都须检验。2 mΩ分流器约0.294 W。Q101按4.5 V栅压最大3.3 mΩ、25°C计算约0.485 W，热态电阻升高，不能用10 V典型值预算。[CSD18540Q5B 官方数据](https://www.ti.com/lit/ds/symlink/csd18540q5b.pdf)。地回流由四层真实铺铜连通，但零未连线不等于地回流压降/温升已合格。

完整 TDK、LM74800/INA300、电流测量/保护保留，前向10 A为源设计目标，未降低源能力设置；前向限流不能约束电机向母线回生电流。源 R1=2.45 kΩ理论10.7971 V，ITRIM17.4 kΩ约11 A设定的典型误差不能作保证12 A硬上限。回生80.6 kΩ/10 kΩ/2.20 MΩ、REF1.25 V名义导通11.3708 V/关闭11.1876 V保持，参考/比较器/容差/共模/温漂与时延仍须实测边界。

外阻1 Ω在约11.4 V吸收约130 W脉冲，厂家50 W连续额定依赖规定散热器，本机小散热板不能自动承诺50 W。源20 J单事件、30 s滚动60 J的50 Hz积分仅是初始软件估计，不是物理I²t硬界；同时制动、外力回推、线束寄生与低电量瞬态尚未验证。16 V电容耐压也不能代替母线/电机端<12 V动态验收。

## 实际铜区 DC 补核（冻结后只读）

`DC_Copper_Regen_Loop_Final.json` 在冻结板图上联合全部实际铺铜多轮廓/空孔、铜盘、线宽和相关THT/过孔，采用二维铜片网络与32扇区孔壁模型。源、新板均按原生70 µm外铜，新板内层35 µm，孔壁25 µm仍是假定；焊接/端接是理想边界。0.10与0.075 mm两档网格求解残差均收敛。没有跨外置RH、MOS或分流器元件按同一网络短接求解。

| 合板路径 | R20估计范围 / mΩ | 网格变化 |
|---|---:|---:|
| W3 SERVO_BUS → W103 RH+ | 3.959–3.984 | 0.62% |
| W104 RH_LOW → Q101漏极 | 0.289–0.296 | 2.36% |
| Q101源极三脚 → RS101.1/2 | 0.246–0.263 | 6.71% |
| RS101.4 → W2输入GND | 0.3718–0.3719 | 0.032% |
| RS101.4 → W4输出GND | 0.4114–0.4116 | 0.046% |

这些范围仅是两档网格的数值变化，不是制造保证误差。MOS源至分流器的短窄段最敏感（约7%），不能把其小数位当精确载流能力。当前所有地铜均参与求解，未以“总铜面积”或单个细地线替代真实平面回流。以RS101.4→W2为终点组合，约66%净电流从正面经内部孔壁转入内/背层；主要分流孔在(25,2)、(15,3)、(28,1)、(36,6)。P101接地PTH也可承担板内换层电流，这不等于其外部AWG28线承担同样电流；外部并行回路没有在该模型中注入。

12个主换层孔的求解分流为每孔6.69–9.90%，合计100%，与简单均分8.33%有差别，见 `Regen_Transition_Current_Sharing.svg`。条件12V/0.99Ω时最高约1.20A/孔；成品孔壁、接触及热态变化仍须验证。不能仅凭孔数宣称通过。

到输入GND的所选板内铜路合计约4.866mΩ，条件12.121A下铜路总压降约59.0mV、损耗0.715W@20°C/0.870W@75°C，其中地回流约4.51mV、54.6mW@20°C。仍须另加MOS、2mΩ分流器、RH、外线和焊接损耗。

同样方法得到旧Regen内部铜路约2.947mΩ，另加旧Power W4→W2地铜约0.096mΩ，合计3.043mΩ；这**未计旧两板之间的正负导线及端接**。新板铜路比该不完整旧铜基线多约1.823mΩ，同时移除了板间线对。只有取得那段真实线束/接点电阻，才可比较完整旧新回路；此记录没有据缺失线阻宣称总体降阻或能力提升。热和实际钳位上界仍未证。
