# C101 卧装电容独立托架 — R22-CAP-001

这是固定到原TDK板H1/H2的真实PEEK托架候选，包含一体前横梁、两个下托、两个独立绑带通道和封口侧避脚止挡。**它没有完成TDK板到机身的主安装，也未通过实体制造、振动、热蠕变或拉脱验收。** 不新增PCB孔，不钻机身承力件，不更改电路。

先看[实际CAD视图](C101_cradle_actual_CAD.png)、[尺寸图PDF](R22-CAP-001_dimensions.pdf)，再读取[主托架STEP](STEP_毫米/R22_C101_PEEK_front_beam_cradle.step)。完整15件清单、源摘要和坐标变换在[manifest.json](manifest.json)，对应STL在[STL目录](STL_装配坐标_毫米)。STEP与STL均为PCB **native毫米坐标**，不能把目录名“装配坐标”当成已施加全机变换。

## 固定方式与制造尺寸

- 原孔H1=(3,3)、H2=(62,3)，孔距59mm；现有PCB孔Ø2.2，托架同轴Ø2.2通孔，不增加孔。PEEK主梁宽65mm，端头Ø5承压柱高4.6mm。
- 电容是原EEUFR1C222，2200µF/**16V**。最大圆柱x6..28，轴线y=-3.5/z=9.1，直径13mm；两引脚和绝缘套按根任务的实际成形参考读取，不作为承力构件。
- 下托位于x8..11和x21..24，座面R6.6，外R8；下部削平到z1.75，不穿过板前面z1.6。两段支托经一体梁把惯性力传给H1/H2；只有柱/梁的规定承压面贴PCB，其余薄壁留出余量。
- 封口侧止挡x5.4..6.0，只挡下方壳缘并避开z9.1的两个出脚。正X端完全开放；对最大壳体端面x28向+X的Ø13×5mm工程通道，本托架没有实体占用。
- 两道编带中心x13和19，分别穿独立2.2×0.8mm槽。编带下行经梁上2.2×0.9mm横向通道，避免把绑带挤在PCB底面。槽的薄底/小圆角需CNC试样检查，不能以模型有效替代工艺验收。
- RS101附近已开x28.6..37.4、y0..0.8的局部缺口；对本轮保守器件包络净隙0.525mm。细化后的器件本体也不得取消这项净隙而不复验。

尺寸图给出孔位置、座面、通道和叠层公差；STEP定义名义实体。绑带接触边需去毛刺并圆滑到R0.15±0.05，CAD没有把这类微小边缘修整逐一建模。主托架须由未增强PEEK棒/板料CNC加工，**不把FDM打印件当成同材料性能**。[Victrex 450G原厂资料](https://cdn.victrex.com/zh-hans/downloads/datasheets/victrex-peek-450g)给出密度1.30g/cm³；这里只用于质量估算，采购材料/退火状态和高温保持力需另外确认。

## 装配与工具路径

1. **在机外台架上**量座面、壳体外径与实际螺钉/叠层。把编带预穿入托架的通道，放置选配衬垫，再通过H1/H2固定托架。
2. H1背面AF4薄扳手从native **-X**进入；H2可从+Y或-X进入。两颗螺钉正面Ø4×30mm直批头预算无碰撞。H1从+Y进入会碰U101/C103，已明确拒绝该方向。
3. 电容先用成形夹具支承封口完成直段/R1弯脚及绝缘套，再以+Z方向由上向下放入支托。机外对电容本体、两根实际成形引脚和绝缘套作了0.5mm步长、0.5–10mm位置核对，无有限体积碰撞；衬垫接触与止挡端面接触单独保留。此采样不宣称连续运动已证明。
4. 每道编带独立闭合与锁结，结位于各自顶部预算内；先做预紧/拉脱筛查，确认电容由衬垫/托架支承且不滑动，再焊引脚。使用外部夹具承受试验力，不能把电流引脚当拉力夹持点。
5. 完成整个板上组件后，按根任务确定的机身安装顺序装入。机内将电容向+Z抬高6mm开始碰LEG5既有固定件，因此**不能在机内直接向上拔出电容**；不得为绕过路径而撬引脚或擅自拆改承力支架。

## 检查结果与边界

[geometry_check.json](geometry_check.json)核对15个新件、113个新板参考件和556个原R20保留件，共10,140对，覆盖真实STL材料距离/相交与必要的精确STEP布尔复核：

- 不存在未解释的有限体积相交。曲面衬垫处不同三角化产生的微小假重叠，经独立STEP布尔确认是接触；螺纹名义根径表示和同一道绳结预算的交叠单独分类，没有泛化豁免。
- 托架与RS101保守包络最小0.525mm，与其中一根成形引脚最小约0.675mm；原生孔/PCB/器件/引脚均未被修改。
- 对旧556件，唯一小于3mm的装态结果是第一绑带顶部结预算与R13_L_key_M2x10约**2.904mm**，相交体积0。不能把本结果写成所有旧件均≥3mm；实际结尺寸/公差仍需控制。
- 正X泄压通道不被本托架占用。整个机器人其他对象与气体扩散、制造商泄压安装要求仍由整机验收处理。
- 这是HOME与机外装入筛查，不是全姿态动态间隙、机身主安装或冲击强度通过。

## 质量、力矩与必须完成的试样验收

[mass_load_budget.json](mass_load_budget.json)给出可复算预算。附件约**2.439g**，含0.30g绑带/绳结估算；紧固件为名义CAD质量，螺纹/倒角/内孔近似会带来误差，应称量替换。电容另设**8g假设预算**，并非厂家称重数据。按二者合计10.439g及假设10g加速度，总惯性力约**1.024N**，相对H1/H2中点的任意方向力矩上界约**15.803N·mm**。这些是载荷输入，不是支架已通过该冲击。

1. 绑带预紧试样扫描0.5、1、2、3N，每道独立锁结；选最低能满足保持力的预紧，不把3N当厂家允许壳体压紧力。两个绑带共同轴向±2N、单道独立1N拉力下无引脚承力/明显滑移，先验收壳套/壳体没有压痕或损伤。若任一失败，修改衬垫或扣结，不能只增加张力。
2. 重做24h、75°C停留后的拉脱，并做热循环，建议筛查滑移≤0.2mm。该温度/时长/门槛是待批准试验条件，不是原厂或已测结论。PTFE的摩擦系数、结保持率、热蠕变均未知；文件只列所需系数，不凭空指定实测值。
3. M2拧紧在真实PCB/PEEK/垫圈/薄螺母上扫描**0.010–0.020N·m**，核压伤、裂纹、松脱和高温蠕变。不可从普通M2钢螺钉额定扭矩继承塑料/薄母叠层额定。
4. 名义叠层4.6+0.3+1.6+0.3+1.2=8.0mm，M2×8只是名义齐平。示例公差叠加会出现螺端相对螺母尾面-0.4至+0.4mm；必须逐件配对，确保**有效啮合≥0.9mm，超出薄母≤0.3mm**，并检查倒角后的实际牙长。不能以“正好8mm”免除这项测量。
5. 重量/保持力/拧紧合格后，才进入全板到机身的振动和结构验证。原R20只提供TDK参考体，本托架不填补未定型的机身主支承。
