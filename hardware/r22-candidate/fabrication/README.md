最小线宽≥0.20 mm；铺铜间距≥0.20 mm。局部逃线0.175 mm：Entry4对、Power15对，位置/UUID见各自制造复核报告。按相应工艺重新审查，不能无条件改成任意便宜叠层。贯穿孔铜厚至少25 µm是电阻估算前提，须确认成品孔壁，不能用表面铜厚代替。

入口板LMZM的PGND与VOUT焊盘各10孔需要填孔并盖铜工艺和钢网/焊接试样确认；否则焊料可能流入孔内。合板换层12孔分流及局部温升仍需实测。Gerber文件不能表达所有焊接/材料要求，因此必须连同两板BOM、装配图、接口和Validation/README交付加工方。

电容EEUFR1C222为卧装成形并独立固定；按托架图在机外预装，不能机器插件后把电容直接弯倒。BM顶插封装与源SM侧插不同，采购料号以本次BOM为准，线端SHR插壳及线序保留。加工前仍需完成主支架、完整线束与热连接设计及首件验收方案。

KiCad自动生成的`.gbrjob`未作为下单文件交付：它从旧PRO默认值读取间距、把轮廓线宽计入尺寸，且合板附带未定义目标的阻抗标记，与当前DRU和设计口径不一致。原始元数据仅以`diagnostics/*.json`保留追溯，处置记录见`automatic_job_disposition.json`。加工使用Edge.Cuts中心线定义名义尺寸，按本文件和各板工艺报告确认叠层/间距；没有指定阻抗目标，不得自行解释为已完成受控阻抗设计。铜、阻焊、钢网和钻孔文件没有为修饰这些元数据而更改。
