## 模型与质量口径

当前 selection 的 733 项确为 468 项原 R20 完全保留行加 265 项新几何/包络；删除的 89 项与新增作用域一致。另 9 项拔插包络单列。所有引用的 STEP/STL 摘要匹配，不能把这个数量改称制造 BOM 件数。Blender 及三张预览图与 278 个读取源摘要一致，733 项读回记录已绑定当前 selection；本审查没有重跑渲染。

质量报告的 5 个新旧裸板算式、材料来源及摘要一致。Entry 裸材名义减少 1.949 g，Power 合板裸材反增 1.012 g，合计裸材约减少 0.937 g；加已列附件毛差约 +0.04 g。该模型未称量器件、焊料、换插头及完整线束，不能据面积缩小或四层结构宣布净减重、新整机 COM、续航或动态平衡通过。总 README 对此已有明确限制。

总 README 也保留了合板到机身主支架、完整线束和热连接尚未闭合的事实；电容托架不是整块 PCB 到机身的主支承。0.025 mm 套管到成形脚名义间隙属于工程包络结果，必须保留成形与绝缘实物验收边界。

## 最终交付绑定

最终 `motion_delta/latest_summary.json` 与 `latest_verification.json` 的源文件摘要、有效 733 项逐件几何/姿态/关节归属均匹配当前 selection。93,595 对具有相对运动的配对在 R21 已记录 195.44175 s 的关节包络内均满足 2.2 mm 目标，最低证书下界 2.230402829 mm。它不是测得的真实最小间隙，也不是重新模拟 R22 的动力学。

65,405 对静态配对分为 65,088 对正间隙、256 对名义零体积贴合、61 对具名螺纹/同体表示，算术分区完整，当前未解释有限交集为 0。动态 2.2 mm 目标不能扩展到这些固定装配面、0.025 mm 套管名义间隙或 73 对针线包络的 0.140089 mm 名义下界。托架的最终 1,980 对组合复核和套管 v2 子集继承已有明确补充入口，旧 113 件参考和旧套管冲突记录被保留为历史证据。

独立核对最终总索引来源、174 个受保护旧文件、运动验证的 1,264 个来源项和 Blender/预览来源；均匹配。暂存映射快照含 1,880 个文件、343 个 Git 目标：每个源文件和副本的字节数及 SHA 相同，目标路径唯一，实际暂存集合无遗漏或过期额外文件。两板根/子原理图、PRO/PCB/DRU、本地库及最终几何入口都在包内，误导性的自动 gbrjob 不在加工集合。
