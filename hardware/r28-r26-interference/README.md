# OpenDuck R28：R26 装配干涉复核

对 R26 的两块新大腿罩，直接重跑连续区间刚体干涉检查。输入为 R26 的 1,224 项装配选择及 R21 四步数值轨迹的 9,773 个积分区间（195.44175 s）；其中 31 项自由颈部线束不适合刚体模型，刚体选择为 1,193 项。**在这条轨迹的名义刚体几何中，两块新罩没有新增穿透；整机仍不能按此结果放行制造或行走。**

| 核对对象 | 结果 |
|---|---|
| 新罩与所有其它刚体项 | 2,383 对；2,345 对随关节运动，38 对变换不变 |
| 连续区间 | 9,773 个；全部动态配对完成覆盖，未解决动态穿透为 0 |
| 保守证明的最小动态间隙 | **0.015113 mm**，发生在右大腿罩与左踝电机的区间界计算中；低于 2.2 mm 的目标值，不是制造公差通过证明 |
| 六处固定安装接触 | 左右罩各与本侧 CNC 桥鞍座、F1/F2 OD7 垫圈相接。原生 STEP 布尔交集体积均为 **0 mm³**；网格的微小交集为数值误差 |
| 旧件之间 | 原 R25 的 46,170 对动态记录与 110 项命名固定接触沿用；本次没有把全部旧件两两重新计算 |

**保留的真实冲突：**R25 下头壳 `R25_lower_head_shell_bottom_entry` 与嘴部载体 `R12_mouth_load_carrier`，在每 0.25° 的张嘴扫描中首次于 **8.75°** 相交，交集约 **0.1225 mm³**；25° 时约 218.58 mm³。此次四步轨迹的嘴部指令仅约 −0.00154° 至 +0.00264°，所以行走回放没有触发该冲突。嘴部全行程不能验收，需修改几何或限位后重新检查。

这项检查使用保存的 R21 轨迹，动力学质量为 4.195094 kg；R26 估算质量 4.443060 kg，并未按新质量重新积分。0.015 mm 是三角网格保守下界，不包含打印误差、紧固件实际偏心、负载变形、线束柔性、地面接触或电机轴承游隙。现阶段只说明受检轨迹没有**新增的名义刚体穿透**，不能宣称所有姿态、所有零件或实物步行无干涉。
