# R23 最终交付勘误

W1 与第二滚转轴承导轨在整个指定关节盒中的最小保守间隙下界为 **2.275125963 mm**，仍超过本轮 2.2 mm 检查目标。此前部分摘要和线束补充目录的 README 写成 2.493111109 mm；该值是某个子盒的下界，不是所有子盒的最小值。

唯一数值来源为 `harness/dynamic_relief_final/dynamic_check.json` 第一项 `minimum_certified_gap_mm`，并已逐项核对等于 `accepted_subboxes[].lower_bound_mm` 的最小值。最终 8 页线束 PDF 中的 2.275126 mm 正确。此勘误不改变导线几何、裁线长度、半径或端接工艺；冻结原始文件保留用于追溯，交付说明与本勘误优先于旧摘要。

S03 对颈俯仰导轨下界 3.746262511 mm，H05 对嘴部承载件下界 2.417452399 mm。整机其他间隙仍按最终刚体与柔性报告分别使用，不能把三对目标值推广到全机。
